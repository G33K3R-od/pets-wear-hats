# Животные носят шляпы — прототип 0.1.0

Отдельный мод для Stardeus. Не требует g33kUI.

В первой сборке: цилиндр для собак колонии, выбор и снятие в разделе управления карточки собаки. Шляпа косметическая: без бонусов, изготовления и расходования предметов. Не требует чипа прямого управления. Есть английский и русский перевод.

Выбор записывается через родную систему внешности в сохранение. Прототип добавляет собаке пустой слой Hat до восстановления внешности из файла сохранения. Другую шляпу и существующие слоты экипировки не перезаписывает.

**Сборка проверена на предоставленных DLL. Саму игру здесь не запускали.** Нужно проверить на тестовом сохранении посадку шляпы, повороты, сон, кнопки и восстановление после загрузки. Параметры DogFit.json предварительные: исходной графики собаки в предоставленных материалах нет.

Установка: папку AnimalsWearHats из архива положить в пользовательскую папку Mods, включить мод и перезапустить игру. Выбрать собаку своей колонии → раздел «Животные носят шляпы» → «Головной убор».

На портретах шляпы пока нет. Кошки, другие животные, физические предметы и рецепты — следующие этапы.

Для настройки посадки изменить DogFit.json и перезапустить игру. Scale — масштаб относительно тела; Down/Left/Up/Right — смещения для направлений; LyingDown — дополнительное смещение лёжа.

Подробности сборки и список игровых проверок — в README.md.
